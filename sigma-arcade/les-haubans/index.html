Les Haubans

Soirée sur la plage : les têtes des mâts lumineux dessinent la courbe de l'exponentielle. Chaque mât est tenu par un hauban planté dans le sable. Pour qu'il frôle la guirlande, une seule place pour le piquet : une unité derrière le mât, quel que soit le mât. La pente du hauban est la hauteur du mât : c'est f′ = f.
