Le Tunnel

Les termes d'une suite sont des lucioles lancées dans un tunnel de nuit. Deux parois qui se resserrent vers la même sortie les y entraînent (gendarmes) ; un plancher qui monte vers +∞ emporte tout ce qui est au-dessus ; un plafond arrête une montée. Les puissances qn s'éteignent, s'emballent ou clignotent.
