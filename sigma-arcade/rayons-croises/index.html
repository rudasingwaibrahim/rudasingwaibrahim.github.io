Rayons Croisés

Escape game laser : le mur de chaque salle est un repère et chaque droite est un rayon. Règle tes émetteurs avec les équations, touche les capteurs… et trouve le point où deux rayons se croisent : c'est leur point d'intersection qui ouvre la porte.

Le cours
Pas tout à fait.

Salle d'entraînement

Labo libre

Règle deux rayons par leurs équations cartésiennes ax + by + c = 0. Le labo affiche leur position relative et, s'ils se croisent, leur point d'intersection exact.
