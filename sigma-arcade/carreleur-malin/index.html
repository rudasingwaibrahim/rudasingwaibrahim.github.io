Le Carreleur Malin

Un produit, c'est un terrain rectangulaire. Développer, c'est le carreler morceau par morceau ; factoriser, c'est recoller les morceaux en un seul rectangle. Chaque carreau posé s'écrit aussitôt dans le calcul.

carreau : aire 1 bande : 1 sur x, aire x grand carreau : aire x² découpe : aire enlevée

Touche maintenant le morceau à couvrir

Au tableau : une série pour toute la classe

Les élèves cherchent sur l'ardoise ou le cahier, puis on corrige ensemble. Cliquez sur un calcul pour le jouer avec le carrelage.
